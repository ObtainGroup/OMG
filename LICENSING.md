## What you may do for free

| Activity | Allowed without a subscription? |
| --- | --- |
| Clone, read and study the source | Yes |
| Install in a Dynamics 365 Tier-1 (dev) box | Yes |
| Install in a Tier-2+ sandbox / UAT environment | Yes |
| Test with a copy of production data in a sandbox | Yes |
| Build extensions, or fork and modify OMG | Yes |
| Demo it to a customer, use it in training | Yes |
| Redistribute your fork (with this license attached) | Yes |
| **Run it in a production environment** | **No — subscription required** |
| **Use it to process live business data anywhere** | **No — subscription required** |

## Production use

Production use requires a current, paid OMG subscription from Obtain ApS,
billed monthly per Dynamics 365 tenant. Contact sales@obtain.dk.

This applies to your own forks and to any extension you build on top of OMG:
if the running solution includes the OMG model, production use needs a
subscription.

## Partners and implementation consultants

You may install, configure, extend and demonstrate OMG for your customers
free of charge in non-production environments. When the customer goes live,
the customer (the tenant owner) needs the subscription.

## What happens after four years

Each released version of OMG converts to the Apache License 2.0 four years
after it was first published. Older versions therefore become fully open
source over time; the current version does not.
