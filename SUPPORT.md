# Support

## What this repository is

This repository is the source for Obtain Message Gateway (OMG). Publishing it
lets you evaluate OMG, run it in your own dev and sandbox environments, and
build extensions on top of it. Publishing it is **not** an offer of support.

## Free (non-production) use

OMG is provided "as is" under [LICENSE.md](LICENSE.md). Obtain ApS has **no
obligation** to:

- respond to issues or pull requests,
- fix any defect, in any version, within any timeframe,
- maintain, update or keep publishing any version, or
- keep OMG compatible with any future Microsoft Dynamics 365 release.

Issues and discussions are welcome and we read them, but nothing posted here —
including a maintainer saying a fix is planned — is a commitment or a
representation that a fix will be delivered.

## Subscribers (production use)

Customers with a current OMG subscription receive support and defect
correction under their subscription agreement with Obtain ApS, which is the
only document that defines response times, supported versions and remedies.
This file does not modify that agreement, and the agreement takes precedence
over anything written here.

Subscribers should raise defects through the support channel named in their
agreement, not through GitHub issues.

## Modified versions and forks

If you modify OMG, or run a fork, Obtain ApS provides no support for the
modified version — including to subscribers. Reproduce the problem on an
unmodified release before reporting it.

## Security vulnerabilities

Report suspected vulnerabilities privately to security@obtain.dk, not as a
public issue. See [SECURITY.md](SECURITY.md). We aim to acknowledge reports
within five working days. Handling of a report is separate from, and does not
depend on, whether you hold a subscription.

## Supported versions

Only the latest published release is maintained. Older releases receive no
fixes, including security fixes, regardless of their Change Date status under
the license.
